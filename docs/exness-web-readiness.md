# Exness Web Readiness

## Official integration boundary

Exness documents algorithmic workflows that connect a Python process to an MT5 terminal, and MQL5 documents the MetaTrader 5 Python package as terminal-based interprocess communication. The practical implication for AkiTrade is that the web app cannot directly and safely become an Exness terminal: a user-controlled MT5 terminal and companion bridge are required for account data or authorized order workflows.

The AkiTrade web workflow must therefore collect no Exness or MT5 password. It can prepare a paper workspace, show the bridge state, provide the official MT5/Exness setup steps, and later accept only a server-side authorization reference or bridge enrollment token generated by the companion service. Live order dispatch remains disabled until a separate, user-confirmed integration release is approved.

## User-controlled preparation sequence

1. Create or select an Exness **demo** MT5 account in the official Exness environment.
2. Install and sign in to the official MT5 terminal on a user-controlled Windows machine or managed terminal host.
3. Install the companion bridge locally beside the terminal. The bridge, not the browser or mobile app, reads terminal state.
4. Pair the bridge using a one-time enrollment token or official authorization reference. Do not paste a broker password into AkiTrade.
5. Confirm that the web dashboard reports a healthy bridge and paper-only mode before using any account data in the dashboard.
